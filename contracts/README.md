# Контракты API

Общие артефакты между сервисами и клиентами.

## Состав

| Файл | Назначение |
|---|---|
| `openapi.yaml` | HTTP API сервиса core — источник истины для фронтенда |
| `asyncapi.yaml` | события и очереди (появится вместе с брокером) |
| `CHANGELOG.md` | история изменений контракта |
| `.spectral.yaml` | правила линта OpenAPI |

Правило: контракт — источник истины для фронтенда и других сервисов.
Меняется сначала здесь, потом в коде.

## Владельцы

| Артефакт | Кто меняет |
|---|---|
| `openapi.yaml` | бэкенд (источник), фронтенд (предложения через PR) |
| `asyncapi.yaml` | бэкенд |

Каталог в совместном владении: изменение не проходит без ревью обеих команд.

## Правила изменения

1. Схема меняется вместе с кодом в одном PR; расхождение — ошибка.
2. Обратная совместимость: удаление или переименование поля — major-версия.
3. Каждое изменение — запись в `CHANGELOG.md` и метка версии.
4. Фронтенд генерирует типы и клиент из схемы, а не пишет их руками.
5. `additionalProperties: false` в схемах — новые поля добавляются осознанно.

## Версионирование

- `v1`, `v2` — major-версии контракта, соответствуют префиксам `/api/v1`, `/api/v2`.
- Внутри версии — только обратно совместимые изменения.
- Deprecated-эндпоинт живёт до следующего major-релиза.
- Поле `info.version` в `openapi.yaml` — версия самого документа контракта.

## Проверка

```powershell
npx --yes @stoplight/spectral-cli@6 lint contracts/openapi.yaml
```

В CI то же самое выполняет `.github/workflows/contracts.yml` при изменении
`contracts/**` или самого workflow.

## Генерация из Laravel

Сейчас спецификация ведётся вручную и синхронизируется с кодом сервиса.
Когда появится `/api/v1`, схема начнёт экспортироваться из Laravel
(Scramble) командой `composer openapi`, а CI будет падать при расхождении
схемы в репозитории и в коде сервиса.

## Будущее разделение

`contracts/` — самодостаточный каталог: `git subtree split --prefix=contracts`
даст отдельный репозиторий с историей. После выноса контракт подключается
к потребителям как зависимость: npm-пакет для фронтенда, composer-пакет для PHP.
