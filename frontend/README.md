# Frontend

Папка зарезервирована под клиентское приложение (SPA).

## Текущее состояние

Пусто — фронтенд ещё не начат. Бэкенд (`services/core`) отдаёт чистый REST API,
поэтому фронтенд не влияет на его работу.

## Планируемый стек

Уточняется. Базовые варианты:

| Вариант | Когда выбирать |
|---|---|
| React + TypeScript + Vite | самая широкая экосистема, много готовых UI-китов |
| Vue 3 + TypeScript + Vite | проще вход, хорош для админок |
| SvelteKit | минимум кода, быстрый рантайм |

## Договорённости

1. **Контракт, а не догадки.** Типы API берутся из `contracts/openapi.yaml`
   (генерация клиента), а не пишутся руками по памяти.
2. **Отдельное окружение.** Свои `package.json`, `node_modules`, `.env` —
   ничего общего с `services/core`. Docker-фрагмент появится как
   `frontend/compose.yml` и подключится в `infra/docker-compose.yml` через `include:`.
3. **Только HTTP-обмен.** Фронтенд не импортирует код бэкенда; авторизация —
   Bearer-токены Sanctum.
4. **Готовность к выносу.** Папка самодостаточна: `git subtree split --prefix=frontend`
   даст отдельный репозиторий с историей.

## Запуск (когда появится код)

```powershell
cd frontend
npm install
npm run dev        # Vite dev-сервер
```

Порт `5173` уже зарезервирован в `infra/.env` (`VITE_PORT`).
